## 🎯 Project Objective

The objective of this project is to transform stroke-related data into an interactive analytical dashboard that helps users:

- Analyze stroke rates across different states
- Compare average, highest, and lowest stroke rates
- Understand population distribution
- Compare age-adjusted and crude prevalence
- Analyze confidence interval ranges
- Identify patterns across different years and categories
- Explore data through interactive filters
- Generate meaningful insights for data-driven decision making

---

## 📌 Key Dashboard Features

### 1. Executive Overview

Provides a high-level summary of the dataset using:

- Total Population
- Average Stroke Rate
- Highest Stroke Rate
- Lowest Stroke Rate
- State-level stroke rate comparison
- Geographic distribution
- Stroke data type distribution
- Year and state filters

### 2. Risk & Confidence Interval Analysis

Analyzes variation and uncertainty in stroke-related measurements using:

- High vs Low Confidence Interval
- Confidence Interval Range
- Stroke Rate vs Confidence Range
- State-level comparisons
- Data Type filters
- Category filters

### 3. Population vs Stroke Analysis

Explores population and stroke measurements through:

- Stroke Rate Per 100K
- Population Distribution
- Stroke Rate by State
- Age-adjusted vs Crude prevalence
- Stroke Category Distribution
- Interactive category filtering

### 4. Key Insights & Recommendations

Uses Power BI's interactive **Decomposition Tree** to drill down into stroke-related measures by:

- Year
- State
- Location
- Data Value Type

This allows users to explore different dimensions of the dataset and identify important patterns.

## 🚀 How to Use

1. Download the `ca2.projectbi.pbix` file from this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open the `.pbix` file in Power BI Desktop.
4. Use the available slicers and filters to interact with the dashboard.
5. Navigate between the dashboard pages.
6. Explore state-level stroke rates, population distribution, prevalence types, confidence intervals, and categories.
7. Use the interactive visuals to identify trends, comparisons, and patterns.

> **Note:** Depending on the Power BI file configuration, the original data source may be required to refresh the dataset.
