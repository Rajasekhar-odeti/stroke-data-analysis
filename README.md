# Stroke Data Analysis Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze **stroke-related health data across states**. The project focuses on comparing stroke rates, population, confidence intervals, data types, and state-level patterns to support data-driven insights.

## Objectives

- Analyze stroke rates across states.
- Compare average and overall stroke-related measures.
- Examine stroke rate distribution by state and data type.
- Understand the relationship between population and stroke rate.
- Analyze confidence intervals and identify states with wider or narrower ranges.
- Provide an interactive dashboard for exploring the data by year, state, category, and data type.

## Dashboard Pages

### 1. Executive Overview
Provides a high-level view of the dataset with:
- Average stroke rate by state
- Stroke data type distribution
- Total population
- Lowest and highest stroke-rate indicators
- State-level stroke-rate distribution
- Interactive State and Year filters

### 2. Risk & Confidence Analysis
Focuses on uncertainty and risk patterns using:
- Stroke Rate vs. Confidence Range
- High vs. Low Confidence Interval comparison
- Confidence Interval Range by state
- Data Type and Category filters

### 3. Population vs Stroke Analysis
Explores population and stroke-rate relationships through:
- Stroke Rate per 100K by state
- Population distribution by state
- Stroke rate by state and data type
- Stroke category distribution
- Interactive question/category filtering

### 4. Key Insights & Recommendations
Uses Power BI's decomposition-tree analysis to explore stroke-related measures by:
- Year
- State
- Location
- Data Value Type

This page is designed to support deeper analysis and communicate findings clearly.

## How to Open

1. Install **Power BI Desktop**.
2. Download or clone this repository.
3. Open `ca2.projectbi.pbix` in Power BI Desktop.
4. Use the slicers and interactive visuals to explore the analysis.

## Important Note

The `.pbix` file is the Power BI Desktop project file. If the original dataset is not included, the dashboard may require the original data source or updated data-source paths when opened on another computer.
